Server Operations Module

Handles Docker container management, health checks, and system monitoring.

Available Commands:

python server_operations.py

Functions:

Function Description
check_container_status(container_name) Check status of a specific container
list_all_containers() List all VLTHR containers
restart_container(container_name) Restart a container
get_system_health() Get overall system health metrics
get_container_logs(container_name, tail) Get recent logs from a container

Pipeline Operations Module

Handles trading pipeline management, data ingestion, and signal monitoring.

Available Commands:

python pipeline_operations.py

Functions:

Function Description
check_pipeline_health() Check pipeline health endpoint
get_pipeline_status() Get current pipeline status
restart_pipeline() Restart the pipeline container
check_data_freshness() Check data freshness for all symbols
restart_ingestion() Restart data ingestion container

Database Operations Module

Handles PostgreSQL queries, maintenance, and data validation.

Available Commands:

python database_operations.py

Functions:

Function Description
check_connection() Check database connection
get_open_trades() Get all open trades
get_account_info() Get account balance and risk information
get_recent_errors(limit) Get recent error log entries
backup_database(backup_path) Create database backup

File Operations Module

Handles log management, configuration files, and file system operations.

Available Commands:

python file_operations.py

Functions:

Function Description
list_directory(path, pattern) List files in a directory
read_file(path, max_lines) Read file contents with line limit
get_recent_logs(log_dir, tail) Get recent log entries
rotate_logs(log_dir, max_size_mb) Rotate log files if they exceed size limit
backup_file(source_path, backup_dir) Create a backup of a file

Workflows & Usage Guide

Predefined workflows for common operations and step-by-step usage guides.

Health Check Workflow

Comprehensive system health check across all components.

1 Check Containers

Verify all Docker containers are running and healthy.

orchestrator.execute_workflow("health_check", {})

2 Check Database

Verify PostgreSQL connection and query performance.

3 Check Pipeline

Verify trading pipeline is running and processing data.

4 Check Data Freshness

Verify OHLCV data is fresh for all active symbols.

Incident Response Workflow

Automated incident response with decision intelligence.

1 Assess Situation

Analyze current system state and identify issues.

context = orchestrator.analyze_situation()

2 Make Decision

AI-driven decision based on context and risk assessment.

action, details = orchestrator.make_decision(context)

3 Execute Actions

Execute validated actions (restart containers, services, etc.)

4 Verify Resolution

Re-assess system state to confirm issue resolution.

Daily Maintenance Workflow

Automated daily maintenance tasks.

1 Rotate Logs

Rotate log files that exceed size limits.

2 Clean Old Logs

Remove log files older than retention period.

3 Vacuum Database

Run VACUUM ANALYZE for PostgreSQL performance.

4 Backup Database

Create automated database backup.

System Recovery Workflow

Full system recovery from critical state.

1 Check All Containers

Identify stopped or failed containers.

2 Restart Stopped Containers

Start all stopped containers in correct order.

3 Restart Pipeline

Restart trading pipeline to resume operations.

4 Restart Ingestion

Restart data ingestion to ensure fresh data.

Quick Start Guide

Step 1: Install Dependencies

pip install requests

Step 2: Configure Paths

Edit each module to set correct paths for your VLTHR installation:

vlthr_root = "/path/to/vlthr"
dashboard_root = "/path/to/dashboard"

Step 3: Test Individual Modules

python server_operations.py
python pipeline_operations.py
python database_operations.py
python file_operations.py

Step 4: Run Orchestrator

python orchestrator.py

Step 5: Execute Workflows

from orchestrator import SOSOrchestrator
orchestrator = SOSOrchestrator()
result = orchestrator.execute_workflow("health_check", {})

Integration with VLTHR System

Environment Setup

Ensure the following environment variables are set:

Variable Description
VLTHR_ROOT Path to VLTHR installation
DASHBOARD_ROOT Path to dashboard installation
POSTGRES_HOST PostgreSQL container name
POSTGRES_USER Database username
POSTGRES_PASSWORD Database password

Docker Integration

All modules use Docker CLI to interact with containers. Ensure Docker is installed and user has proper permissions.

Database Integration

Database operations use docker exec to run PostgreSQL commands inside the container. Ensure the database container is running.
