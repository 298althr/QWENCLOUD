Environment Variable Management

How to set variables safely on Alibaba ECS without exposing them to GitHub.

The Problem

GitHub is public. If you put API keys in a file and push it, anyone can read them. The solution is to keep secrets only on the ECS server, never in the Git repository.

How It Works
FilePurposeIn Git?
.envReal secrets (API keys, passwords)NO gitignored
.env.devDev secrets for Docker DesktopNO gitignored
.env.exampleTemplate with blank fieldsYES safe, no values
docker-compose.ymlUses ${PUBLIC_URL} substitutionYES no secrets
docker-compose.prod.ymlReads from .env on ECSYES no secrets
Step-by-Step: Set Variables on Alibaba ECS
1

SSH to your ECS instance

Connect to your server using SSH or the Alibaba Cloud console terminal.

ssh root@47.84.106.210
2

Navigate to the project directory

cd /root/QWENCLOUD/TRACK4
3

Pull the latest code from GitHub

This pulls the clean code without secrets.

git pull origin track4
4

Create the .env file on the server

Copy the template and fill in real values. This file stays on the server only.

cp .env.example .env
nano .env
5

Fill in your real API keys

Set the values that the application needs. These are never pushed to GitHub.

DASHSCOPE_API_KEY=sk-your-real-key
QWEN_API_KEY=sk-your-real-key
PUBLIC_URL=http://47.84.106.210:3000
JWT_SECRET=a-random-long-string
TELEGRAM_BOT_TOKEN=your-bot-token
6

Set file permissions

Restrict access so only root can read the file.

chmod 600 .env
7

Rebuild and restart containers

Docker Compose reads .env automatically and passes variables to containers.

docker compose -f docker-compose.prod.yml up -d --build
8

Verify the application is running

curl http://localhost:3000/api/health
# Should return: {"status":"ok"}
