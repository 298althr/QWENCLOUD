Target length: 3 minutes · Updated July 19, 2026

Demo goal

Show that ALTHR is an AI agent that runs server operations on its own. It watches your servers, figures out what is wrong when things break, and fixes problems without a human typing commands. Three AI modules debate every action before it runs. A 7-layer safety framework checks each action. A human approves anything risky. Everything is logged.

Key pages to show:

  • Landing page at / (new, for evaluators)
  • Dashboard at /dashboard (live metrics, kill switch, simulate incidents)
  • AI Assistant at /agent (natural language chat with Qwen models)
  • Approvals at /approvals (human-in-the-loop queue)
  • Safety and Audit at /security (SAF 7-layer, audit log, security scan)
  • Settings at /settings (kill switch, guardrails, budgets)

Security features to mention during the demo

  • API key and JWT authentication on all routes
  • WebSocket authentication on connection handshake
  • Rate limiting: 100 requests per minute, 20 burst max
  • Input validation with Zod on every API endpoint
  • CORS locked to frontend origin
  • CSP headers via Helmet
  • Audit logging with client IP capture
  • Session timeout (30 min default)
  • Kill switch for emergency stop
  • Human-in-the-loop approvals for risky actions

Qwen models used

  • qwen-turbo - Intent parsing, simple classification
  • qwen-plus - DRE proposals, DREV reviews, root cause analysis
  • qwen-max - Complex diagnosis, multi-step reasoning, CRDS veto
